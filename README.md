# Multi-Agent AI System for Automated Business Operations

A Python-based multi-agent AI system that uses **Google Gemini and LangChain** to automate common business operations. A Manager Agent analyzes user requests and assigns them to specialized agents such as **Customer Support, Task Management, and Business Report Agents**. The system generates the final response in the terminal and automatically saves the complete result as a downloadable `.txt` file on the user's Desktop.

### Technologies Used

* Python
* LangChain
* Google Gemini API
* Multi-Agent AI
* File Handling
